# Phase 0 Decision Log

Decisions taken while scaffolding the repository where the normative documents left a choice open. Each entry
states the choice, the constraint it satisfies, and how it can be revisited. None weakens a Level 2 requirement.

| P0-01 | Shared provider-free library `src/shared/EnterpriseForms.Integrity` holds canonicalization (`RowHmac/v1`) and Merkle v1; referenced by the Authority (sign+verify) and business `Application` (verify only). | Both planes must produce identical bytes; one reviewed implementation avoids drift (SEC-38). It contains no keys, HTTP or persistence, so it does not breach the trust boundary. | If the business plane must never compile verification code, split into a verify-only package. |
